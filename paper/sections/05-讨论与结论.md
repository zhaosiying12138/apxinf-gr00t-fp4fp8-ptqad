# 5. 讨论与结论

## 5.1 恢复训练怎样推进 PTQ 的可用范围

本文研究的核心问题是：在闭环任务质量约束下，恢复训练能否允许更多权重从 FP8 转为 NVFP4。这个问题需要把量化覆盖、恢复残差和成功率放在同一个比较中。纯 PTQ 的参考是精度分配阶梯；恢复后的参考还应包括新增低秩参数的编码载荷。只有在计入这些成本后，同等压缩下行为更稳健，或同等行为质量下能够采用更高的量化覆盖，才能说明方案推进了可用范围。

第 4 章的受控结果按这一路径组织。相邻阶梯保留已有 FP4 集合，只增加明确定义的模块，因而可以定位压缩增量对应的行为变化；同一选定基座上的 QAD、继续 QAD 和 QAD+OPD，则用于区分演示适配、额外训练和学生分布蒸馏的作用。解释结果时，需要同时阅读每任务的成功数、真实分母和配对初态，不能只从一个总成功率推断所有任务都得到相同程度的改善。

PTQ 本身是否退化，应由测量决定。若某一级已经接近 BF16，恢复训练能观察到的绝对提升空间有限；较高的成功率并不自动证明训练具有额外价值。相反，某一级显著退化也不保证低秩更新能够恢复。报告预定停止规则、全部已完成的开发级别、冻结的纯 PTQ 前驱参考和两个续训分支，才能让正收益、无明显差异及负收益具有同样清楚的证据身份。

## 5.2 局部误差、低秩适配与学生分布监督

PTQ 与恢复训练作用于不同层次。Hessian 校准和 GPTQ 根据实际激活方向衡量单层权重误差，目标是减小固定输入分布上的输出扰动。模块精度保护进一步限制敏感位置的扰动。但机器人动作会改变下一次输入，因而局部重建误差较小仍不能保证执行轨迹不偏离。正文的协变量漂移分析解释了这一差异，也说明为什么离线权重误差、速度场误差和闭环成功率应分别测量。

QAD 在冻结量化基座上增加低秩修正 $\Delta W=(\alpha/r)BA$。它提供的是受限的函数调整空间：训练不必更新全部权重，却能够修改任务相关的特征变换和动作生成。低秩约束同时限制了可表达的修正，因此不能把所有量化误差都预设为低秩，也不能仅凭训练损失下降宣布行为恢复。本文以演示流匹配监督训练这一修正，并通过完整模型闭环检查其最终作用。

OPD 进一步改变监督所覆盖的状态。采集策略是已经完成 QAD 的学生；教师在该学生实际访问的观测上提供速度场目标。师生共享观测、动作端点、噪声和时间步，在 LIBERO 有效动作掩码内比较预测，因此损失针对的是同一个插值问题。完整张量仍参与前向，只有 16×7 个有效位置直接进入教师损失；填充位置不贡献该损失对输出的直接梯度。共享网络的参数更新仍可能同时改变有效与填充位置的预测。

这一设计可以看作对学生访问区域施加教师函数约束，但其效果仍受教师质量和采集覆盖限制。固定缓存只描述采集时学生的状态分布；参数更新后，学生可能访问新的区域。一轮缓存蒸馏因此具有明确的数据边界，不能直接等同于持续重新采样的 on-policy 学习或完整 DAgger。教师在这些观测上的预测也不必然最优，过强的约束可能限制有益的任务适配。教师权重、采样频率和缓存规模需要在开发协议中确定，并保持最终评测独立。

## 5.3 APXInf 生态提供的系统连接

APXInf 使低位宽表示能够从文件走向真实执行。核心张量类型、设备算子、模型 Blocks 和机器人策略接口分别承担不同职责：量化格式在编码器中定义，缓冲与矩阵合同由后端检查，模型层决定路由，服务层负责观测和动作交换。新增精度可以沿这一分层接入，保留现有模型的前处理、状态管理和策略接口。

本文围绕这些连接点完成了具体实现。离线产物保存 E2M1 数据、swizzled E4M3 块缩放和 FP32 张量缩放；加载器将三者一起传给设备算子；CUDA 适配器以约定的二级缩放和行主序输出交付结果。NVFP4 Blocks 通过组合既有 BF16 实现复用模型功能，同时按实际产物选择精度。图执行使用持久中间缓冲、context 所有的 GEMM scratch 和捕获前准备的算法缓存，避免把图中引用的地址当作短期临时对象。

相应的验收分成数值和生命周期两部分：非方形矩阵、非单位缩放、正负值与零块用于核对算子输出；脏缓冲、不同尺度的同形状层和改变输入后的重复 replay 用于核对资源复用。本轮 GPU 上这两组检查均通过，完整 π0.5 的 `RequireGraph` 测试也通过了有限性与同模型 eager/graph 输出比较，范围见附录 A.4.4。这些结果支持当前输入、形状与二进制上的图执行约定，不把 NVFP4 eager/graph 一致性解释为 NVFP4 与 BF16 的行为质量相同。

| 系统层次 | 本文实现或组织的工作 | 对应的验证对象 |
|---|---|---|
| 数值表示 | 完整浮点格点、最近偶数舍入、零与极小尺度处理 | 独立编解码参考和边界测试 |
| 校准与分配 | 完整模型二阶统计、固定张量缩放的 GPTQ、嵌套精度清单 | 实际执行层、逐层方法和产物预算 |
| 原生计算 | CUDA/Rust 适配、在线激活量化、缩放传递与输出布局 | 同量化输入的设备矩阵乘结果 |
| 模型接入 | 压缩权重加载、π0.5 FP4 Blocks、变体与回退路由 | 文件覆盖与实际执行覆盖 |
| 恢复产线 | 加性 LoRA、学生采集、掩码教师损失、完整导出 | 梯度、训练预算、权重身份和索引 |
| 闭环接口 | 常驻服务器、串行任务驱动、官方初态恢复与账本 | 初态配对、逐集结果和实际分母 |

这些交付把格式、模型和实验连接为可检查的流程。共享权重的规范来源、处理器与模型动作长度、实际归一化统计以及完整 checkpoint 键集合，同样属于系统正确性：单层公式正确，并不能替代这些接口约定。源文件摘要、恢复 manifest 和重置状态摘要，使同一次实验的代码、模型与轨迹能够相互对应。

APXInf 的系统贡献也需要按实际执行路径解释。本文 GR00T 的恢复闭环使用 PyTorch 反量化和 BF16 合并权重；APXInf 原生 FP4 的算子与 π0.5 路由另行测量。两者采用相容的策略服务形式，为后续迁移提供基础，但 GR00T 闭环成功率和另一条引擎路径的加速不能拼接成一个已经完成的原生低比特部署指标。

## 5.4 编码预算如何转化为部署收益

编码预算首先回答指定表示需要多少权重字节。NVFP4 每个元素占半字节，每 16 个元素另有一个 E4M3 块缩放，每个张量还需要一个 FP32 二级缩放；FP8 则包含逐行缩放。完整模型预算继续加入未量化张量，恢复方案还要加入低秩旁路。源 checkpoint 分别保存词嵌入与输出投影的共享别名，本文因而同时提供物理文件口径和已知别名去重口径，并保证每个比值的分子、分母采用相同规则。

本次 `head+lang_all` 恢复范围有 58,580,992 个可训练参数。若以独立 BF16 旁路部署，其权重载荷为 117,161,984 字节；训练时的 FP32 参数、梯度和优化器状态另行计量。这部分成本相对完整基座较小，但仍会改变最终压缩比，也会引入额外矩阵乘和访存。省略旁路成本，会高估恢复方案相对纯 PTQ 的优势。

当前闭环导出把低秩修正合并回基座 dtype，得到完整的稠密 BF16 checkpoint。它便于直接使用现有策略加载器，却没有兑现 packed 权重的实际文件压缩；合并后权重也通常不再位于原量化格点。代数上相等的“低比特基座加旁路”和“稠密合并矩阵”，在有限精度下还会因运算次序不同而产生差异。

原生执行又多一项变量：当前 FP4 算子同时量化激活，而恢复闭环采用 weight-only 扰动。前者的基座运算是 $Q_x(x)Q_w(W)^\top$，后者是 $xQ_w(W)^\top$；加入高精度旁路并不能自动消除这项区别。完整 GR00T 部署应明确激活量化规则和旁路计算精度，依次验证单层输出、完整速度场或动作块，再进行同协议闭环评测。必要时还应把新增激活扰动纳入训练。

性能评价也沿同一边界展开。大矩阵可能较好地利用低精度计算能力，小矩阵则更容易受到启动、量化、转换、算法查询和缓冲管理影响。真实部署收益应由打包文件大小、常驻权重显存、峰值显存、模型延迟和完整策略延迟共同描述；TFLOPS、平均功耗或某个算子的倍率都不能单独替代这一组测量。

## 5.5 受控比较的范围与局限

继续 QAD 与 QAD+OPD 共享初始适配器、冻结基座、演示批量、更新步数和新优化器，因此可以估计“加入这套学生分布蒸馏流程”带来的增量作用。OPD 同时增加学生访问数据、教师标签和探针计算；它并不是等总数据或等 FLOPs 的比较，也不能将全部变化唯一归因于某一种教师信号。若进一步分解来源，需要在相同采集观测上增加自模仿或无教师标签对照，并单独控制额外前向、反向预算。

有效批量只描述一次更新消费多少演示窗口，不能代表唯一演示数。固定数据池中的重复抽样、窗口之间的重叠和任务分布，都会影响训练暴露。本文记录实际微批、累积数、更新数和采集来源，避免把更多优化步骤写成获得了更多独立轨迹。辅助 RWR 入口提供任务级奖励加权自模仿思路；它与完整的 PPO、DPPO 等策略优化方法具有不同目标和数据要求，本文不由该入口推断这些方法的优劣。

最终评测在 LIBERO-10 的官方初态表上使用固定且互不重叠的开发、采集与评测索引。不同模型的稳定后状态摘要用于核实环境初态配对，逐任务结果用于检查改善是否集中于少数任务。有限回合仍存在抽样波动；任务之间难度和误差容忍度不同，尤其在接近满分时，应结合实际分子分母理解百分点变化。服务器按任务固定推理随机种子，但不同轨迹长度可能改变后续随机数消费，因此环境初态配对不等于逐 episode 的策略噪声完全相同。

硬件实验限于本文列明的单张笔记本 Blackwell GPU 与软件环境，温度、功率限制和系统负载均可能影响延迟与功耗。LIBERO 仿真上的内部对照也不能直接推出其他任务套件、真实机器人或其他设备上的收益。跨论文比较还需核对初态子集、执行步长、终止条件和模型版本；本文不以不同协议的分数建立 SOTA 排名。

## 5.6 结论

本文形成了 APXInf 生态下 GR00T 混合量化与恢复训练的一套完整研究流程：用可验证的数值格式和完整张量清单建立 PTQ 基座，通过嵌套配方提高 NVFP4 覆盖，在冻结基座上进行低秩演示适配，再以学生实际访问状态上的掩码教师监督开展一轮蒸馏。完整导出、共享别名处理和官方初态账本，使方法、产物与闭环结果能够相互核对。第 4 章的同协议结果给出各阶段的行为变化及其成本，恢复是否扩大纯 PTQ 的可用范围据此判断。

面向部署，下一步是把保留低位宽基座的 GR00T 低秩旁路接入原生执行，明确激活精度，并在相同权重身份与评测协议下测量真实存储、显存、延迟和成功率。进一步缩小残差秩、迭代学生采集或扩展任务与硬件，都应沿用这条从数值、函数到闭环的验证链。这样，量化比例、行为保持和执行收益才能成为同一个已部署策略的共同属性。
