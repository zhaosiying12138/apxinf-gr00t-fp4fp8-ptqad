# 摘要与引言

视觉—语言—动作模型（Vision–Language–Action model，VLA）把相机观测、语言指令和机器人状态映射为动作。对这类模型，低位宽量化的目标不只是减少权重占用，还要保持动作反馈到环境之后的任务成功率。本文围绕 **APXInf 生态、GR00T N1.7、NVFP4 W4A4、定制训练后量化（PTQ），以及量化基座上的 QAD/OPD 恢复**，建立一条从数值表示、校准、闭环恢复到 LIBERO 评测的可复现实验链。

本文的 W4A4 契约很具体。普通 NVFP4 Linear 的主分支先把输入转为 F16，再沿最后一维按 16 个元素求块最大值；激活路径的二级 scale 固定为 $1.0$，最后在 E2M1 格点上舍入。v11 将 479 个 eligible 权重张量全部编码为 NVFP4，其中 469 个普通 Linear 与 7 个 CategorySpecificLinear 接入 W4A4 activation QDQ，3 个 embedding/position 张量只做权重量化。若模型在量化基座上训练 LoRA，前向写成

$$
y=\operatorname{Linear}(Q_A(x),W_q)+\frac{\alpha}{r}\operatorname{Linear}(\operatorname{Linear}(x,A),B).
$$

其中 $Q_A$ 只作用于量化基座，恢复分支始终读取原始 BF16 $x$；激活块的除数只有在 scale 为零时才取 1，正 scale 原值保留。QAD 在 `all_ordinary_linear` 范围的 468 个普通 Linear 上用成功演示轨迹修正量化误差；OPD 在 QAD 之后再加入学生访问状态上的教师速度监督；continued-QAD 使用相同追加步数，作为“只是多训练”的对照。

**结果状态。** 新 v11 协议的完整 160 回合五臂账本仍在运行，正文中的成功率和压缩比例统一保留为红色占位符，直到原始日志、reset identity 和配对摘要全部通过校验。快速 smoke 只验证服务启动、W4A4 张量契约和观测采集接口，不进入主表，也不用于证明 QAD 或 OPD 的增益。

**关键词：** VLA；GR00T；APXInf；NVFP4；W4A4；PTQ；QAD；OPD；LIBERO。

## 1.1 为什么闭环量化比静态误差更难

策略每次生成一段动作，机器人只执行其中一部分，然后把新的图像和状态再次送入模型。一次从环境重置到成功或超时的尝试称为 **episode**；这种反复决策称为**闭环**。如果量化让夹爪移动得稍短，下一次观测就会改变；后续动作面对的是另一个状态，最初很小的数值误差可能最终变成任务失败。因此，静态均方误差只能帮助选择量化参数，不能替代完整环境判定。

本文分别报告三个量：编码预算、闭环成功率和原生算子延迟。编码预算回答“低位宽表示占多少字节”；成功率回答“机器人是否完成任务”；延迟只在明确的 APXInf/π0.5 原生入口中测量。三者使用不同的实验入口，不能互相代替。

## 1.2 从表示到行为的逻辑链

完整 checkpoint 先建立逐张量清单，记录形状、共享别名、校准来源和目标格式。PTQ 决定哪些矩阵使用 NVFP4，并用块缩放与 GPTQ 补偿把误差限制在量化格点上。W4A4 服务端和训练端随后使用同一个 activation QDQ；如果只在权重上做 FP4 而让激活保持 BF16，得到的是 W4A16，不能作为本文的 W4A4 结果。

QAD 和 OPD 都以冻结的 $W_q$ 为基座。QAD 的监督来自成功演示，OPD 的额外监督来自学生已经访问过的状态；因此 OPD 只有在学生分布确实偏离演示分布时才有独立信息。continued-QAD 采用同样的追加更新预算，用来排除“训练更久”这一解释。

## 1.3 本文贡献

1. **统一的 W4A4 数值契约。** 固定 F16 输入、16 元素块、E4M3 scale、E2M1 格点和二级 scale=1.0，并用 CPU oracle、Torch device path 与真实 GR00T 服务逐层核对。
2. **恢复分支的结构约束。** 明确禁止把 $W_q+BA$ 合并后再做 activation QDQ；正式部署保留 base 和 A/B adapter，使 QAD/OPD 的 BF16 残差不被错误量化。
3. **五臂闭环归因。** 在同一 v11 bank 上比较 BF16、W4A4 PTQ、QAD、continued-QAD 和 QAD+OPD；只有 OPD 同时高于 QAD 与 continued-QAD，才把增益归因于学生状态蒸馏。
4. **可审计复现包。** 公开协议、代码哈希、训练/评测日志、图表和 Ubuntu 原始截图；读者可以从 HTML/知乎稿阅读方法，从 v11 协议重跑，再按 episode reset identity 复核结果。
