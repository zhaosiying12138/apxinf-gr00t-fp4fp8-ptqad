# 摘要与引言

视觉—语言—动作模型（Vision–Language–Action model，VLA）把相机观测、语言指令和机器人状态映射为动作。对这类模型，低位宽量化的目标不只是减少权重占用，还要保持动作反馈到环境之后的任务成功率。本文围绕 **APXInf 推理生态、GR00T N1.7、NVIDIA 的四位浮点格式 NVFP4、定制训练后量化（PTQ），以及量化基座上的行为恢复**，建立一条从数值表示、校准到 LIBERO 闭环评测的可复现实验链。

本文要回答的问题是：当权重和激活都采用四位表示，即 **W4A4**（4-bit weights and 4-bit activations）时，怎样在保留低位宽基座的同时恢复机器人行为？方法分为三个阶段。PTQ 用少量校准数据生成 NVFP4 权重，并接入激活量化；**QAD（本项目中的量化后演示适配）**用成功演示训练低秩修正；**OPD（学生访问状态上的教师监督）**固定选中的 QAD 学生采集一轮观测，再以教师标签辅助恢复训练。OPD 使用固定缓存，不持续在线采集与更新。三个阶段是否带来闭环收益，由同一组独立初态上的对照实验判断。

**审阅状态。** 五臂实验尚未完成，每臂计划评测 160 回合。成功率和压缩比例暂留红色占位符，待原始日志、初态身份与配对摘要通过校验后回填。当前稿用于审阅方法与结构，尚不宣称 QAD 恢复或 OPD 独立增益已经成立。

**关键词：** VLA；GR00T；APXInf；NVFP4；W4A4；PTQ；QAD；OPD；LIBERO。

## 1.1 为什么闭环量化需要行为恢复

策略每次生成一段动作，机器人执行其中一部分，再把新的图像和状态送回模型；这种反复决策称为**闭环**。一次从环境重置到成功或超时的完整尝试称为 **episode（回合）**。如果量化让夹爪移动得稍短，下一次观测就会改变；后续动作面对的是另一个状态，最初很小的数值误差可能最终变成任务失败。因此，静态均方误差可以帮助选择量化参数，但任务是否完成仍须由环境判定。

## 1.2 从 PTQ 到 QAD，再到 OPD

PTQ 从已有模型权重和少量校准输入出发，确定量化尺度与舍入结果，不进行恢复训练。本文先建立逐张量清单，记录形状、共享关系、校准来源和目标格式，再将 GPTQ 的权重误差补偿适配到 NVFP4 的块缩放规则。训练与服务使用相同的激活量化规则，使后续恢复面对的误差与评测时一致。

**LoRA（Low-Rank Adaptation，低秩适配）**用两个小矩阵的乘积表达修正，训练时只更新这两个矩阵。本文沿用工程中的 **QAD** 名称，具体指“量化后演示适配”：冻结量化基座，用未量化教师成功执行任务所形成的演示训练 LoRA。这一阶段使用演示任务损失，不额外加入教师速度蒸馏项。

**OPD** 在本项目中指“学生访问状态上的教师监督”。先固定选中的 QAD 学生，执行一轮闭环任务并收集观测；再由未量化教师对这些观测给出动作生成过程中的速度标签；最后从该 QAD 检查点继续训练，同时使用演示与教师标签。采集完成后缓存固定，训练期间不持续采集新状态，也不在线更新教师。因此，这里的监督覆盖采集时的学生分布，不能直接等同于持续在线的策略蒸馏。

为判断 OPD 的作用，另设 **continued-QAD（继续 QAD）**：从同一个 QAD 检查点出发，追加相同数量的演示更新，但不使用学生状态上的教师监督。OPD 与 QAD 的差异反映追加阶段的总效果；OPD 与 continued-QAD 的差异才用于检验教师监督是否提供额外收益。

## 1.3 本文贡献

1. **面向 NVFP4 的 PTQ 与一致的 W4A4 路径。** 将块缩放和 GPTQ 误差补偿结合，统一训练与服务的激活量化规则，并用 CPU 数值参考、Torch 设备路径和真实 GR00T 服务核对。
2. **保持量化基座的恢复结构。** 在冻结的四位基座旁训练独立低秩分支；该分支读取原始高精度输入，避免部署时改变训练所用的模型。
3. **区分恢复效果与追加训练效果。** 在相同任务和初态上比较 BF16（bfloat16，一种 16 位浮点格式）基线、W4A4 PTQ、QAD、continued-QAD 和 QAD+OPD，分别检验量化退化、演示恢复和教师监督增益。
4. **连接方法、执行与复现证据。** 提供协议、源码与权重身份、逐回合日志、图表和 Ubuntu 执行截图；APXInf 原生算子与图执行另行测量，使行为结果和执行成本各有可核查的依据。

## 1.4 量化范围与实现边界

W4A4 描述量化主分支的权重与激活，不表示整个模型的每个张量都以四位存储或计算。v11 的量化清单包含 479 个符合量化条件的权重张量：469 个普通线性层（Linear）、7 个按机器人类别选择权重的线性层（CategorySpecificLinear），以及 3 个词嵌入或位置参数张量。479 个张量的权重全部采用 NVFP4；前两类共 476 个线性算子接入激活量化，后 3 个张量只做权重量化。QAD/OPD 的 `all_ordinary_linear` 恢复范围为其中 468 个普通 Linear；恢复分支与其他未量化张量仍须单独计入成本。

当前 GR00T 使用 **QDQ（Quantize–Dequantize，量化后再反量化）**模拟低位宽数值：先舍入到量化格点，再用浮点算子计算。普通 NVFP4 Linear 主分支先把输入转为 F16（即 FP16，16 位浮点），沿最后一维按 16 个元素求块最大值；块缩放采用 E4M3（8 位浮点），数据采用 E2M1（4 位浮点）格点，激活的二级缩放固定为 $1.0$。归一化除数仅在块缩放为零时取 1，正缩放值保持原值。格式与舍入规则在第 2 章展开，算术过程见第 3 章。

正式评测保留量化基座与独立 LoRA 分支：主分支读取量化激活，恢复分支读取原始 BF16 输入；具体前向公式见 §3.3。两者不合并后再量化输入。本文分别报告**编码预算、闭环成功率和原生执行延迟**：编码预算计入格式缩放、未量化张量与恢复分支；成功率来自 LIBERO 完整回合；原生延迟来自 APXInf 算子或 $\pi_{0.5}$ 执行入口。GR00T 的 Torch QDQ 结果不能写成原生 APXInf GR00T W4A4 内核的加速结果。快速冒烟测试只验证服务启动、数值规则和观测采集接口，不进入闭环主表。
