# OPD 速度监督的噪声与时间重放审计

日期：2026-10-07。只读检查主工程和实际安装的 GR00T 源码，并运行 CPU 复核；未加载完整检查点、未运行 GPU、未修改训练或推理路径。

## 结论

未发现当前 OPD 教师缓存与学生辅助前向因观测文本、图像或序列长度不同而抽到不同 `(noise, t)` 的缺陷。对同一个缓存样本，两者复用相同输入、种子、模型参数 dtype 和 flow 配置，并在 `eval` 模式下重放。当前前向中，观测内容不控制噪声抽样次数；Qwen、DiT 和状态 dropout 在该模式下关闭。

这个结论针对 **缓存教师速度与学生 OPD 辅助前向**。主 QAD 演示损失使用另一批输入和正常训练随机数，无需与辅助前向共享插值点。训练的随机直线插值也不是推理的四步 Euler 轨迹，不能用缓存 MSE 直接证明动作或闭环恢复。

## 两组端点统一由 QAD 生成的解释范围

对教师访问状态和学生访问状态，都用同一冻结 QAD、相同端点生成规则生成动作端点，再由同一 BF16 教师按相同速度种子标注，能够去除“一个使用教师端点、另一个使用学生端点”的额外混淆。两组端点的数值仍会随观测不同而变化，这是固定条件策略对输入变化的响应，不是额外改动生成方法。

只有在任务/初态身份、样本数量、时间采样规则、教师调用、噪声/时间规则、更新次数及起始 QAD 都匹配后，两组 KD 差异才可解释为这套固定监督程序下的**状态来源效果**。它不自动证明纯状态漂移机制：相同查询分位不保证相同抓取/放置阶段，教师成功筛选限定了共同身份人群，固定一次学生缓存也不是随训练持续更新的 on-policy 分布。独立动作诊断与闭环配对结果仍需另行提供。
