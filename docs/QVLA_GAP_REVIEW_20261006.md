# QVLA 对照审阅：当前 W4A4 QAD/OPD 还缺哪些证据

审阅日期：2026-10-06。本文是研究评审与后续实验建议，不是已完成的实验报告。审阅期间现有 v12 训练继续运行；未修改冻结协议、训练目标、数据分区或检查点，也未启动额外 GPU 作业。

**结论：QVLA 暴露出的主要差距是强 PTQ 对照、动作层面的机制证据和验证广度。当前五臂实验用于检验 RTN 量化后的损失能否恢复；即使观察到恢复，也还不能证明优于先进 PTQ，更不能直接证明 GR00T 原生 NVFP4 部署的端到端收益。** 本项目值得集中验证的问题是：在视觉、语言及动作生成路径的可量化主分支均采用 NVFP4 W4A4 时，低秩恢复和学生状态教师监督能否维持闭环能力。

QVLA 表 1 的 OpenVLA-OFT 数据是 BF16 **97.1%**、QVLA W4A4 **96.0%**，下降 **1.1 个百分点**；`96.0 / 97.1 ≈ 98.9%` 是性能保留率。其报告显存由 15.4 GB 变为 4.5 GB，`4.5 / 15.4 ≈ 29.2%`；1.49× 是该论文的速度测量。不能把这些数字写成“98.9% 绝对成功率”“压缩后参数只剩 29.2%”，也不能与本项目不同模型、任务和硬件的结果直接排名。

QVLA 的四位整数格式与 NVFP4 也不等价。NVFP4 仅数据和块尺度就需要 `4 + 8/16 = 4.5 bit/元素`，还未计二级尺度、padding、未量化参数与 LoRA。论文式 (7) 和公开分配器按通道数计算平均位宽；不同层每行长度不同，通道平均位宽并不等于按参数元素加权的位宽，更不等于实测显存。

## 3. 优先补的六项

| 优先级 | 缺口 | 为什么影响核心结论 | 最小可落实补充 |
|---|---|---|---|
| P0 | 只有 RTN 恢复对照，还没有足够强的同模型 PTQ 参照 | 仅从 RTN 恢复不能推出优于 PTQ SOTA；若起点弱于同预算校准 PTQ，仅报告恢复幅度可能高估相对优势 | 在相同 GR00T、数据分区、实际编码预算下加入已核验的 NVFP4 GPTQ；加一个保护敏感动作模块的 PTQ 参考点并如实计入 BF16 字节。后者是覆盖消融，不替代 W4A4 主结果 |
| P0 | 缺少“速度损失改善 → 最终动作改善 → 闭环改善”的测量 | 当前 OPD 在同一插值点匹配教师速度；GR00T 推理还要经过四次 Euler 积分，局部速度拟合不自动等于正确动作 | 固定观测与初始噪声，比较五臂最终动作块；分别报告有效 16×7 动作的归一化误差、反归一化后的平移/旋转误差、夹爪判定差异，再观察配对 rollout 的首次偏离与失败阶段 |
| P0 | OPD 对照尚不能单独识别“学生状态”这一机制 | continued-QAD 控制相同演示更新预算，未匹配 OPD 的额外教师计算，也未排除“任何额外教师蒸馏都有效”的解释 | 同一 QAD 起点比较 continued-QAD、演示状态教师蒸馏、学生访问状态教师蒸馏；匹配更新数与演示读取数。两个教师蒸馏臂还应匹配端点生成规则、随机上下文、教师项系数、缓存大小及探针次数，另报实际计算成本 |
| P1 | 当前恢复范围与误差来源没有实验连接 | QVLA 指出 projector/action head 敏感，但不能直接把 OpenVLA 的观察当成 GR00T 的结论；我们 category 层量化后也没有 LoRA | 在固定诊断输入上分别干预视觉、语言、跨模态接口、动作头和 category 分支，测最终动作变化。仅将单模块 BF16 回退用作定位对照，主方案继续 W4A4 |
| P1 | 验证仍局限于一个任务套件和一个训练种子 | 十任务的新初态只能证明同任务条件下的泛化；不能证明未见任务、跨套件或跨模型泛化 | 当前冻结评测完成后另立补充协议。优先增加合适 checkpoint 的第二/其余 LIBERO 套件和训练种子；BF16 必须先具有基本任务能力。CALVIN/第二模型与实机属于更高成本扩展，不应伪称已具备 |
| P1 | GR00T 原生执行与行为证据尚未合并 | QDQ 主分支用浮点算子执行；参数编码预算和 π0.5/算子速度不能推出 GR00T 部署的显存或端到端加速 | 打通实际 packed NVFP4 基座＋独立 BF16 LoRA 的 GR00T 服务，先核对数值/动作，再测同一模型、同一输入形状的常驻/峰值显存、p50/p95 策略延迟，最后复验闭环 |

上述 P0 是支撑方法价值的最低补充；没有必要为形式完整同时启动所有 P1 工作。GPTQ 是强基线建设的起点，单加一个 GPTQ 对照仍不足以声称超过 PTQ SOTA；更强主张还需要可复现、适配 GR00T 和激活四位约束的先进 PTQ 参照，包括动作敏感度方法。当前长训练完成前不改变其冻结实验定义。

## 4. QAD 与 OPD 的机制还需要讲清楚

### 4.1 当前代码的目标是什么

`rl/lora_qad.py` 明确记录两种 objective：无探针时是 `demo flow loss`，有探针时是 `demo flow loss + scheduled sequential teacher velocity MSE`。因此本项目的 QAD 标签指成功演示上的量化后 LoRA 恢复；它不是自动等同于文献中的教师 KL 或完整 Quantization-Aware Distillation。

`rl/probe_distill.py::ProbeAnchor.loss` 读取缓存观测、学生动作端点、种子及教师速度，用相同随机上下文计算有效动作区域的速度 MSE。这个随机回放合同是已有优势。需要补的是它对完整策略的效果测量，而不是再次用训练 loss 证明闭环恢复。

学生状态蒸馏还存在两种漂移：环境观测会随策略变化；积分中的动作状态也会随速度场变化。当前只采一轮 QAD rollout 并固定教师缓存，追加训练后的 OPD 策略可能离开这两个已采样分布。因此一轮缓存只能称为“学生访问状态上的离线蒸馏”，不能套用迭代 DAgger 的完整保证。

比较演示状态与学生状态时还必须控制插值端点。现有缓存入口可分别使用演示动作和学生预测动作；直接比较会同时改变观测分布与动作端点。若要单独检验学生访问状态的价值，两组端点都应由同一冻结 QAD 在各自观测上生成，并统一教师、噪声与时间采样规则、有效掩码及归一化协议。否则结论只能描述两套蒸馏数据配方的差异。

### 4.2 建议的最小诊断

固定一组与正式 held-out 分开的诊断观测、相同初始噪声和动作归一化参数，按下面顺序测量：

1. **相同插值点的速度差**：回答教师项是否真正改善自身目标。将训练缓存与独立诊断缓存分开报告。
2. **完整四步积分后的动作差**：所有模型各自生成动作轨迹；只比较有效动作。位移、旋转和夹爪分开，以免混合量纲掩盖关键控制错误。
3. **各自闭环的行为差**：同初态、同任务和配对种子；报告成功/失败转换、首次明显偏离发生于接近、抓取、搬运还是放置阶段。各自访问了不同观测时，动作差本身不再是纯量化误差，必须和固定观测诊断区分。

在同一观测与噪声下，四步 Euler 的误差可分解为“当前位置的速度拟合误差”与“积分状态已经不同所引起的误差”。若教师速度场在相关区域是 L-Lipschitz，步长为 h，令 e_k 表示学生与教师第 k 个积分状态的距离，η_k 表示在学生当前积分状态上比较两者速度的误差，则有 `e_(k+1) ≤ (1 + hL)e_k + hη_k`。当前缓存只约束部分插值点的 η，尚未测出完整推理轨迹上的误差界；这正是需要最终动作诊断的原因，不能把这个条件性不等式写成已验证的闭环保证。

只在以上诊断显示“训练缓存拟合好、当前学生访问状态仍偏离”后，再考虑第二轮状态重采集；只在显示“局部速度更准、完整动作仍不准”后，再考虑完整动作块蒸馏或沿实际 Euler 轨迹的监督。这样新增训练对应可观察的问题，不靠盲目增加步数或系数。

## 6. 对终稿和接下来的具体影响

1. **相关工作立即补齐**：将 QVLA 的动作敏感度、平均位宽与 BF16 保护范围写入背景，避免把“VLA 低位宽且维持成功率”单独当成新贡献。本次已修改相关工作与参考文献源文件，未重建尚待结果的公开终稿。
2. **现有五臂仍完成**：它回答同一 W4A4 基座上的恢复是否有效，也避免因一时中间分数改变实验。当前没有最终 v12 分数可引用。
3. **接着补强 PTQ 和三层动作诊断**：这是判断后续投入方向的最高价值信息。诊断只能用其预先指定数据；最终 held-out 不用于挑方案。现成 GPTQ 的[复用审查](GPTQ_REFERENCE_REUSE_AUDIT_20261006.md)发现校准初态映射缺失；已补[可追溯捕获校准入口](CAPTURED_PTQ_CALIBRATION.md)，复用既有 Hessian/GPTQ 算法。[完整动作诊断入口](ACTION_CHUNK_DIAGNOSTICS.md)也已准备，但两者的真实 GPU 测量尚待当前五臂完成。
4. **若主张 OPD 的独立机制**：补演示状态 KD 对照，再判断是否需要更新学生缓存。仅 OPD 高于未续训 QAD 不足以隔离教师项；仅高于 continued-QAD 也不足以隔离学生状态分布。
5. **收益与任务范围对应**：同 LIBERO-10 的配对成功率、参数编码预算、实测显存与原生策略延迟分别陈述。未经同口径基线验证，不写“超过 QVLA/PTQ SOTA”；未经原生 GR00T 验证，不把 APXInf 的独立算子或其他模型加速写成 GR00T 的端到端收益。

建议围绕这一研究问题组织文章：**在包括动作生成模块的 NVFP4 W4A4 主分支上，用低秩演示恢复与学生访问状态蒸馏弥补精度损失，并检验恢复是否超过相同演示更新预算的续训及强 PTQ 参照，同时报告额外教师计算成本。** 结果决定这个问题最终能回答到哪一步。

## 7. 2026-10-07 复核：新证据对优先级的影响

本次复核沿用上文固定的 QVLA v1 及作者源码快照，重读动作敏感度、位宽预算、表 1 和 §4.1 的模块保护约定，并核对本项目新完成的开发集记录。以下是当前实现的候选筛选数据，不是最终测试结果；没有据此改动冻结协议或启动额外 GPU 作业。

BF16、RTN W4A4 PTQ、首个 QAD 候选（学习率 `5e-5`，2,000 步）分别为 **46/50、41/50、42/50**。PTQ→QAD 的净增 1 回合来自 **7 次失败转成功、6 次成功转失败**；另有 35 回合均成功、2 回合均失败。两个摩卡壶上灶任务中 QAD 为 4/5，BF16 为 2/5，也说明“更接近教师动作”和“闭环更成功”不能直接画等号。第二个 QAD 候选及后续 OPD 比较尚未完成，不能提前给出恢复结论。

核验来源为 `results/reruns/rtn_w4a4_release_20261006_01/selection_final/{bf16,rtn_w4a4_category}/` 和 `recovery_v12/artifacts/dev_qad_lr_5e-05/` 的逐任务日志、`task_results.json` 与 `summary.json`。三臂全部 50 个计分回合的完整环境 reset 记录一致；策略随机数在每任务开始时播种，不据此声称不同策略在每个回合消耗了相同的扩散噪声序列。本地内部事实表 `paper/_build/qad_first_dev_20261007.md` 保存逐回合互换及来源哈希，不进入终稿结果表。

这些结果提高了逐任务分析的优先级，但不改变 §3 的证据要求：

| 需要回答的问题 | 已有准备 | 仍然缺少的证据 |
|---|---|---|
| 恢复是否稳定，而非不同任务的改善与退化相抵？ | 五臂配对统计及逐任务动作指标入口 | 完整五臂测试；必要时检查实际失败轨迹 |
| 恢复是否优于同覆盖校准 PTQ？ | 已冻结 GPTQ 补充协议与可追溯校准输入 | 真实校准、量化及配对闭环结果；GPTQ 单独仍不代表 PTQ SOTA |
