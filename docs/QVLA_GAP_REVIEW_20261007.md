# QVLA 二次对照审校：终稿仍需补齐的内容

审校日期：2026-10-07。本文档只记录对 QVLA（arXiv:2602.03782，ICLR 2026）正文、附录和作者代码快照的二次核对，以及当前稿件需要补齐的说明或证据。没有读取 v12 的 held-out 结果，也没有启动新的 GPU 作业。

代码快照仍固定为 [`26cc4821a3be4c003d09d3c7997b38db2a347982`](https://github.com/AutoLab-SAI-SJTU/QVLA/tree/26cc4821a3be4c003d09d3c7997b38db2a347982)。已有较完整的初次审阅见 [`QVLA_GAP_REVIEW_20261006.md`](QVLA_GAP_REVIEW_20261006.md)。本次只补充此前容易被读者忽略的细节。

## 结论

当前工作的科学问题仍然成立：在 GR00T N1.7 的可量化主分支上施加固定 NVFP4 W4A4 压力后，QAD 和 OPD 能否恢复闭环行为。QVLA 已经解决的是另一层问题：在 OpenVLA 系列上，用动作空间敏感度为每个输出通道选择整数位宽，并在平均位宽预算下做全局分配。因此本文不能把“全量 NVFP4 W4A4 + 低秩恢复”描述成 QVLA 的改进版，也不能把 RTN/GPTQ 对照直接写成超过 VLA PTQ SOTA。

终稿需要让读者一次看清三件事：

1. 两篇文章的“四位”不是同一种格式，也不覆盖同一组模块。
2. QVLA 的强证据包含动作空间误差和短时累计误差；当前工作必须用自己的动作诊断把 QAD/OPD 与闭环变化连起来。
3. 本文的贡献边界是恢复训练和学生状态教师监督在固定 NVFP4 W4A4 压力下的作用；跨模型、跨套件、实机和原生 GR00T 加速暂时不能由现有证据推出。

## P0：终稿必须补齐

### 0. 固定论文与公开代码的复现边界

二次读取作者代码快照 `26cc4821a3be4c003d09d3c7997b38db2a347982` 后发现，论文方法描述与代码职责需要分开写。`qvla/sensitivity_hessian_proxy.py` 先累积每层输入协方差，计算带阻尼的逆 Cholesky 对角项，再按输出行生成 `proxy_b`；论文正文的理论段落则把它概括为 Jacobian 增益与量化噪声的一阶乘积。该脚本默认 `--max_samples=32`、`--bits=0,2,4,8`（16 位由未量化旁路表示），而论文附录报告的是 512 条轨迹；其读取器只接受同时存在 `text` 和 `image` 的校准记录，也不会自动纳入论文所说的仅指令补充样本。`qvla/inject_fake_w.py` 明确实现的是 weight-only fake quant：对目标 Linear/Conv2d 的权重行做对称舍入，projector、action_head 和 `language_model.lm_head` 被排除，脚本内没有 activation QDQ 或 A4 kernel。因而论文表格中的 W4A4 运行时结果不能仅凭这个脚本复现；终稿应把“文献报告的 W4A4”与“公开代码可直接执行的 weight-only 注入”分开，避免把实现缺口误写成本文基线结果。

### 1. 在相关工作中给出 QVLA 的真实机制

当前稿提到了 QVLA，但还应明确写出其核心计算。对第 `l` 层第 `c` 个输出通道，QVLA 分别试验 `b∈{0,2,4,8,16}`，用 teacher-forcing 下的单步动作误差

`s_lc^(b) = E ||A_tilde_lc^(b) - A*||²`

以及短回合累计误差

`S_lc^(b) = E Σ_t ||A_tilde_lc^(b)(t) - A*(t)||₂`

衡量扰动，再用 Jacobian 增益与量化噪声构造一阶 proxy，通过 greedy demotion 满足全局平均位宽预算；`0 bit` 表示剪枝。这样读者才能理解 QVLA 是“动作空间、通道级、混合位宽”的分配方法，而本文是“固定格式、全覆盖主分支、训练恢复”的方法。

这里要保留一个容易被混淆的细节：正文 Eq. (5) 的累计指标是逐时刻二范数之和，附录 G 为便于一阶推导又定义了平方范数形式的真实敏感度。两者是不同的记号和统计量，不能在本文中写成同一个“累计 MSE”。QVLA 的公开 `sensitivity_hessian_proxy.py` 也不是直接计算完整 Jacobian，而是用输入协方差和阻尼逆 Cholesky 生成行级 proxy；终稿应把“理论目标”“论文中的验证指标”“代码中的便宜 proxy”分开。

### 本次重读新增的缺口：证据层级与适用范围

QVLA 的实验不是只有表 1 的平均成功率。它至少有六层互相支撑的证据：

1. **模块与通道敏感度**：projector、action head 的模块级敏感度，以及同一层内通道间的异质性；
2. **时间累积**：固定输入的动作误差随时间增长，并比较逐层量化和通道分配；
3. **分配消融**：channel-wise 与 layer-wise、uniform-bit 与逐级 demotion、是否允许 0-bit，以及 gate ratio；
4. **校准规模**：128/256/512/1024 条轨迹的稳定性；
5. **迁移验证**：UniVLA-7B、CALVIN 和真实 IMETA-Y1/ALOHA 任务；
6. **定性行为**：抓取过冲、接触不稳、提前释放、恢复动作抖动等失败阶段。

当前本文只准备复现其中与 GR00T W4A4 恢复链直接相关的两层：固定观测下的动作块误差，以及正式 LIBERO 闭环的配对成功率。因而终稿必须明确写出：本文没有复现 QVLA 的 action-aware channel allocation，也没有跨模型、CALVIN、真实机器人或 QVLA 的 gate-ratio 证据；这些是适用范围的限制，而不是可以用 APXInf 算子基准替代的内容。

若希望把 QVLA 对照做得足够完整而不扩大研究问题，最小补齐方案是：

- 在动作诊断中增加 rollout 内的累计误差或首次偏离阶段，并给出一张定性失败阶段图；
- 在表格中同时报告本文的可量化覆盖率、QAD/OPD 的恢复范围和完整编码预算；
- 增加一个“同格式保护范围”诊断（action head/projector/category 层保护与全 W4A4 的行为差异），说明全覆盖压力是实验设计而非敏感度最优解；
- 在讨论中明示没有 GR00T 同模型的 packed W4A4 p50/p95 延迟与显存，因此不能把独立 π0.5/APXInf 结果写成 QVLA 意义上的端到端 speedup。

### 2. 加一个口径对照表或等价段落

至少应在引言或实验设置中同时列出以下事实：

| 项目 | QVLA | 本项目 v12 |
|---|---|---|
| 四位的含义 | 每输出通道从 `0/2/4/8/16` 选择的平均整数权重位宽；激活为统一 INT4/INT8 | 权重为 NVFP4 E2M1，16 元素共享 E4M3 块尺度和 FP32 二级尺度；激活用 NVFP4 QDQ |
| 覆盖范围 | 主要量化 vision backbone 与 language module；projector、action head 保持 BF16，公开脚本还排除 `lm_head` | 479 个 eligible 权重张量全部 NVFP4；469 个 ordinary Linear 和 7 个 category Linear 安装 A4 QDQ；QAD 只训练 468 个 ordinary Linear 的 BF16 LoRA，category 层冻结 |
| 结果口径 | OpenVLA-OFT：BF16 97.1% → W4A4 96.0%，显存 15.4 → 4.5 GB，1.49×；RTX 4090、LIBERO 四套件 | GR00T N1.7、LIBERO-10、RTX 5090 Laptop；正式评测为十任务、五臂各 160 个配对回合；编码预算计入块尺度、padding、未量化参数和 LoRA |

QVLA 的 `98.9%` 是 `96.0/97.1` 的相对性能保留率，不是 98.9% 的绝对成功率；其 W4A4 也不是“每个张量固定四位”。这些数字只能作文献参照，不能与本文直接排名。

### 3. 把动作级机制证据做完整

QVLA 同时报告单步 Action-MSE、短时累计动作/末端偏差和最终成功率。当前 `ACTION_CHUNK_DIAGNOSTICS.md` 只规划了固定观测上的完整 16×7 动作块差异，且尚未运行 GPU；它不能单独替代 QVLA 的 rollout 累计证据。

最终至少需要报告以下三层中的前两层：

1. 相同观测、相同初始噪声下的完整动作块误差，按平移、旋转和夹爪分别统计；
2. 正式策略 rollout 的累计动作偏差，或首次偏离所在阶段（接近、抓取、搬运、放置）；
3. 若实现成本可接受，再报告末端位姿/接触阶段的误差。

若只完成第一层，正文必须把它称为固定观测诊断，不能写成对闭环稳定性的直接证明。

### 4. 明确 PTQ 主张的边界

QVLA 的主表在同一模型上比较 SmoothQuant、OmniQuant，并在附录比较 AWQ、GPTQ；本文的 RTN 与即将补充的 NVFP4 GPTQ 只能回答“同一 GR00T W4A4 覆盖下，恢复链相对这些参考基座如何”。

因此终稿应使用“在固定 NVFP4 W4A4 基座上恢复闭环能力”这样的表述，除非完成同模型、同覆盖、同激活格式的 action-aware PTQ 对照，否则不要写“超过 QVLA”或“刷新 PTQ SOTA”。

## P1：可补实验，也可在正文明确范围

### 5. 说明校准/监督数据不是同一概念

QVLA 附录使用 LIBERO 训练集随机 512 条轨迹，并做 128/256/512/1024 的校准规模消融。本文当前 37 条 BF16 成功轨迹、148 个窗口是 QAD 的演示监督数据，不是 PTQ calibration，不能与 512 条轨迹作数量比较。GPTQ 补充实验应在表中写清真实观测数、层覆盖和是否使用激活 QDQ。

### 6. 给全覆盖 W4A4 一个定位消融

QVLA 用 layer-wise/channel-wise、统一位宽/剪枝和 gate ratio 消融解释其分配策略。本文若不增加 action head/projector/category 回退到 BF16 的诊断，至少应明确：全覆盖 W4A4 是为了制造可恢复的压力，而不是已经证明的最优位宽分配；QAD 的 LoRA 覆盖范围比量化范围窄，是当前实验设计的非对称性。

### 7. 加条件性理论边界

本文已有层输出误差传播不等式，但应在公式后明确写出：这是局部线性和有限步长下的条件性近似，不能给出闭环成功率保证。QVLA 的 Jacobian proxy 也依赖局部线性和各向同性噪声假设，不能把该 proxy 当成真实动作敏感度本身。

### 8. 不把独立引擎结果写成 GR00T 部署收益

QVLA 的 1.49× 是同一 OpenVLA-OFT 模型入口上的速度测量。本文目前的 APXInf π0.5、单算子和 QDQ GR00T 证据属于不同测量范围。若未完成同一个 GR00T packed W4A4 服务的常驻/峰值显存与 p50/p95 策略延迟，摘要只能报告编码预算和独立引擎验证，不能报告 GR00T 端到端加速。

## 建议的终稿落点

建议把 QVLA 对照压缩成引言中的一个口径表、相关工作中的一段机制定义和讨论中的一段范围声明；不要把全文写成 QVLA 复现。本文最清晰的主线仍是：

`固定 NVFP4 W4A4 PTQ 压力 → QAD 演示恢复 → continued-QAD 控制额外训练 → OPD 学生状态教师监督 → 动作诊断与 LIBERO 闭环配对检验`。

五臂结果、动作诊断和 GPTQ 参考完成后，再决定 OPD 是否有独立增益；在结果出来以前不应预写任何提升百分比。
