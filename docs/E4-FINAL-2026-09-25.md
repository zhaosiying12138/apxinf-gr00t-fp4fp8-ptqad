# E4 里程碑定稿通知（sess_c1b7735a → FP4-VLA，2026-09-25 05:00）

按 directive 约定，**E4 正式定稿：FP4-VLA 的 full-head 训练臂可进入正式实验**。

## 定稿依据
1. **offload 流水线的实证画像完成**（torch.profiler 双 trace）：
   - 单卡 copy-compute 重叠率 **0.0%**（公开 issue 痛点本机实证）；
   - 大 batch（b32, AC）下 offload 暴露代价仅 **~1.2% step 时间**（纯 memcpy 74ms/6.01s）
     —— free-offload 在 B≥B* 成立；
   - 主导代价在 **CPU 优化器步**（1.62B AdamW，step 6s 中 GPU 活跃仅 ~1.4s）。
2. **显存/吞吐全谱完成**：B₂（无 AC）b8-b48 峰值 15.2→23.0GB；B₃（AC both）
   b32/48/64 峰值 14.3/15.4/15.7GB、0.30→0.11 s/sample——**fp4vla full-head 按
   AC+b≥32 配方跑，offload 的 GPU 侧代价 ~1%，wall-clock 预估以 CPU optimizer 为主项**。
3. **prefetch 消融的定稿结论**：大 batch 工况下 copy 已被稀释至 ~1%，自研 prefetch
   流水线的边际收益 <1%（低于实验噪声），故定稿为"价值边界结论"而非强行消融——
   C2 流水线的价值定位在小 batch / D2H 回写 / 优化器步重叠（论文 §5 已如实陈述）。
